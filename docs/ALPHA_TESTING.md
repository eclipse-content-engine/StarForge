# Public alpha testing

The `0.3.0a1` release is intentionally limited. Keep backups, export to a new
plugin, and validate important outputs with xEdit, the Creation Kit, and the
game before using them in a real mod.

When filing feedback, include:

- StarForge version and installer or portable build
- Windows version
- operation and body type
- expected and observed behavior
- exact on-screen error text
- whether recovery succeeded

Never attach game plugins, BA2 archives, purchased game assets, private evidence,
or credentials. A minimal synthetic reproduction is ideal.
